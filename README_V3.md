# V3: власні меми та голосовий тригер

Запуск із вікном перегляду:

```bash
venv/bin/python its_giving_v3.py --no-vcam
```

Скажи **«у»** (або фразу з цим окремим словом, наприклад «у моєму»).
Відео `assets/guitar_voice.mov` програється зі звуком один раз до кінця.
Скажи **«що»**, щоб запустити `assets/vlad_voice.mp4` зі звуком один раз до кінця.
Цей ролик заповнює весь кадр зі збереженням пропорцій; зайві краї обрізаються по центру.
Команда «що» працює також із власною фразою `--voice-phrase` для гітари.
Це розпізнавання слова, а не детектор будь-якого звуку «у» всередині інших слів.
Коротке слово може випадково спрацьовувати в розмові або розпізнаватися із затримкою.

Для точнішої фрази:

```bash
venv/bin/python its_giving_v3.py --no-vcam --voice-phrase "у моєму"
```

- `g` — вручну запустити гітарний ролик.
- `j` — вручну запустити ролик «що».
- `v` — вимкнути/увімкнути голосовий тригер; повторити підключення після помилки мікрофона.
- `p` — ролик для вказування пальцем у камеру.
  Жест також працює збоку: витягни вказівний, зігни середній, безіменний
  і мізинець. Великий палець можна відвести вбік; точно цілитися в об’єктив не потрібно.
- `r`, `t`, `l`, `b` — rock, thumbs_up, log_carry, bouquet.
- `e` — нове фото `rock_left`: жест 🤘 лівою рукою. Правою рукою 🤘 запускає
  `rock` із музикою та SWAG-плашкою. Якщо показати обидві руки, пріоритет має права.
  HUD підписує визначену руку як LEFT/RIGHT; підтримується також `--no-flip`.
- `d` — HUD, `q` — вихід.
- `--no-voice` — запуск без активного мікрофона.
- `--mic 0` — вибрати мікрофон за індексом (за замовчуванням системний).

Реакція `rock` має оригінальний синтезований басовий біт `assets/rock.wav`
(110 BPM, цикл 8,73 с, низький синтезатор і саббас). Він починається разом із фото, повторюється, поки реакція
активна, і зупиняється при її завершенні. Відтворити WAV заново можна командою
`venv/bin/python scripts/make_rock_beat.py`.

На HUD є стан мікрофона, шкала рівня звуку, назва пристрою та рядок **«Почув»**
з українським текстом, який повернув розпізнавач.
`QUIET INPUT` означає, що звук дуже тихий або надходять нулі;
`NO AUDIO DATA` — аудіоблоки перестали надходити;
`MIC ERROR` або `MODEL ERROR` супроводжуються поясненням помилки.
Якщо рівень постійно `−120 dB`, перевір **Системні параметри → Приватність і безпека
→ Мікрофон**: доступ потрібен програмі, з якої запущено скрипт (Terminal, VS Code
або Codex). Після зміни дозволу перезапусти цю програму та скрипт.
Під час будь-якого відео або музики `rock` та 0,6 секунди після них голосові команди ігноруються,
щоб звук із динаміків не запускав ролики повторно. Звук відтворюється через
системний аудіовихід Mac; віртуальна камера передає лише відео.

Розпізнавання працює локально через Vosk та українську модель
`models/vosk-model-small-uk-v3-nano`. Модель уже завантажена в цю папку проєкту.
Аудіо з мікрофона обробляється в пам’яті й не зберігається та не надсилається в мережу.
За потреби дозволь мікрофон терміналу в налаштуваннях приватності macOS.

На іншому комп’ютері встанови залежності через `pip install -r requirements.txt`
і завантаж [українську модель Vosk](https://alphacephei.com/vosk/models/vosk-model-small-uk-v3-nano.zip)
у `models/`, зберігши назву її папки. Для звуку відеореакції використовують
однойменний WAV поруч із MOV та системний програвач macOS `afplay`.

### Sigma

Витягни й стисни губи, трохи примруж очі або насуп брови, як на фото-прикладі.
Утримай вираз 4 кадри: запуститься `assets/sigma.gif` (Man Sigma GIF).
Клавіша `s` запускає GIF вручну. Жести рук мають пріоритет над виразом обличчя.

### Cinema

Підніми дві відкриті долоні по різні боки обличчя, випрями пальці й утримай
4 кадри. Запуститься `assets/cinema.gif` (Bungo Stray Dogs Cinema GIF).
Клавіша `c` — ручна перевірка. Обидві руки й обличчя мають бути видимі камері.
